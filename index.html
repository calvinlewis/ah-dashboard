Hour-by-hour recommendation

Logic: recommend HRV mode (ECO 10 min/hr, 20 min/hr, or CONT) using indoor absolute humidity & dew point plus outdoor temperature and humidity (to compute outdoor absolute humidity / dew point).

Rules (summary)

  • Moisture-risk override (any season): if indoor dew point > +4°C (cold-season condensation risk) → CONT.
  • Deep-cold dryness recovery: if outdoor < −10°C AND indoor AH ≤ 5.1 g/m³ → ECO (temporary, 24–48h, comfort-driven).
  • Winter (outdoor < −5°C): default 20 min/hr, but CONT if indoor AH > 8.5 g/m³.
  • Shoulder (−5°C ≤ outdoor < 15°C): CONT if indoor AH ≥ 6.5 g/m³, else 20 min/hr.
  • Summer (outdoor ≥ 15°C): default 20 min/hr. Recommend CONT only when outdoor air is drier than indoor air (outdoor AH ≤ indoor AH − 0.5 g/m³, or outdoor dew point ≤ 12°C).
